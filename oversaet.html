MyMemory er gratis uden konto. Uden e-mail kan man oversætte omkring 5.000 tegn om dagen, med e-mail omkring 50.000.

Med en nøgle til Cloud Translation API kan du oversætte op til 500.000 tegn om måneden gratis. Nøglen gemmes kun på denne telefon.

Teksten genkendes på telefonen. Kun selve teksten sendes til oversættelsestjenesten, aldrig billedet.
