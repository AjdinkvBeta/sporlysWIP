# Sporlys og værktøjer

Små værktøjer, der kører helt på telefonen. Intet sendes til en server.

Åbn: https://ajdinkvbeta.github.io/sporlyswip/

| Værktøj | Side | Hvad det gør |
| --- | --- | --- |
| Sporlys | `index.html` | Tegn efter en skitse med kameraet eller som lysbord. Skitsen fastgøres til papiret og følger med. |
| Scanner | `scanner.html` | Tag billeder af dokumenter, ret dem op, fjern skygger og gem som PDF. |
| Mønster | `moenster.html` | Lav perleplader (Hama Midi), korssting og pixel art ud fra et billede eller fra bunden. |
| Oversæt | `oversaet.html` | Oversæt tekst live fra kameraet, fra billeder eller skrevet tekst. Mange sprog, også asiatiske og kyrilliske. |
| PDF | `pdf.html` | Skriv, tegn, marker, dæk over, underskriv og sæt billeder ind i PDF'er. Drej, flyt og slet sider. |
| QR-kode | `qr.html` | Lav QR-koder til links, tekst, wifi, kontakter, SMS, e-mail og telefon. |
| Filer | `filer.html` | Konvertér mellem mange filtyper, zip, formindsk billeder, saml og del PDF'er. |

Skift værktøj med menuen øverst til venstre.

Biblioteker i `assets/vendor` (alle MIT/Apache): JSZip 3.10.1, pdf-lib 1.17.1, pdf.js 6.2.108, marked 18.0.10, js-yaml 3.15.1, docx 9.8.1, xml-js 1.6.11.
Hentes fra nettet ved brug: tesseract.js 5.1.1 (tekstgenkendelse) og lamejs 1.2.1 (MP3).
Oversættelse: MyMemory (gratis) eller egen Google Cloud Translation-nøgle.
